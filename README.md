YouTube View Bot

A simple Python browser-automation project that demonstrates automated browser interaction, randomized timing, and mouse movement.

Requirements

Python 3.x

Microsoft Edge

PyAutoGUI

Installation

Create a virtual environment:

python -m venv .venv


Activate it on Windows:

.venv\Scripts\activate


Install the required package:

pip install pyautogui

Usage

Run the program with:

python main.py


Enter the URL when prompted.

This project is provided for educational and browser-automation experimentation purposes. Automated traffic may violate the rules or terms of the website being accessed. Use responsibly and only on websites where you have permission to automate activity.
